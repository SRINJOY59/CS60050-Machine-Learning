# 📘 CS60050 - Machine Learning

This repository serves as a consolidated archive of coursework, assignments, and supplementary resources for the **CS60050: Machine Learning** course. It encompasses foundational to advanced concepts, with hands-on implementation of various algorithms and models.

---

## 📁 Repository Structure

```plaintext
CS60050-Machine-Learning/
│
├── ML_Assignment1/        # Assignment 1: Linear and Logistic Regression
├── ML_Assignment2/        # Assignment 2: Decision Trees and Random Forests
```

## 📝 Assignments Overview

### 🔹 Assignment 1: Linear & Logistic Regression
- Problem statements in PDF format
- End-to-end implementation using NumPy
- Linear and logistic regression models built from scratch
- Analysis, result visualization, and performance evaluation

### 🔹 Assignment 2: Decision Trees & Random Forests
- Focused on tree-based models and ensemble learning
- Complete implementation of Decision Trees and Random Forest algorithms
- Feature importance and overfitting analysis

### 🔹 Assignment 3: Clustering on CIFAR-10
- Implementation of **K-Means** and **Gaussian Mixture Models**
- Feature extraction from visual and textual modalities
- Comparative study on clustering performance
